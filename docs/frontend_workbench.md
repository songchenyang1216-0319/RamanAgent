# 前端工作台

## 入口

启动后访问：

```text
http://127.0.0.1:8000/app/index.html
```

## 当前工作台区域

- 登录 / 注册
- 项目中心
- 文件中心
- 任务中心
- 工具目录 / Tool Schema
- Raman Benchmark / 训练
- 审计日志
- 报告中心
- Pipeline 抽屉
- 知识库抽屉
- Skills 管理抽屉

## 长任务交互

文件中心里的批量分析和报告导出默认走异步任务分支。任务中心支持：

- 查看日志
- 查看结果
- 查看产物
- 订阅任务事件
- 取消 pending/running 任务

## 设计边界

前端只做状态展示、表单收集和结果渲染；算法逻辑必须留在后端或 `raman_core`。
